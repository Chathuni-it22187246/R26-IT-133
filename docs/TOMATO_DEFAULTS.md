# Tomato climate defaults — superseded by Phase 2.1 evidence

Phase 2 stored **preliminary Demo Mode placeholders** (for example nursery 22–26 °C / 24 °C and 65–75 % RH / 70 %). Those numbers were **not** evidence-backed.

Phase 2.1 **audited and replaced** them. Do not treat the Phase 2 table as current app recommendations.

See:

- [`CROP_CLIMATE_EVIDENCE.md`](CROP_CLIMATE_EVIDENCE.md) — traceable evidence matrix, source IDs, classifications and gaps
- [`DEMO_CONTROL_LOGIC.md`](DEMO_CONTROL_LOGIC.md) — Circulation / Exhaust / Fogger **project rules**

Current Tomato suggested starting profiles are defined in `CropProfileRegistry` (profile version `2.1.0`) from Shamshiri et al. (2018) Table 4 and supporting citations. They are **research-supported suggested values**, not a universal standard and not an official Sri Lankan greenhouse standard.
